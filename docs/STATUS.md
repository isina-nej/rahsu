# وضعیت توسعه و تحویل راه‌سو

## پیاده‌سازی‌شده و پوش‌شده
- React/MapLibre فارسی با انتخاب نقشه، جست‌وجوی اختیاری و نمایش موانع، مصرف و عدم‌قطعیت.
- Django/DRF و PostGIS؛ واردکننده داده OSM تهران و اسکلت مسیریاب OSRM.
- تطبیق محافظه‌کارانه موانع با نام خیابان و تایید مدیر، سناریوهای چراغ و سرعت‌گیر.
- مدل فیزیکی مصرف سوخت با سناریوی شتاب/توقف و شیب اختیاری.
- کالیبراسیون آفلاین VT-Micro با داده‌های اندازه‌گیری‌شده و holdout جداگانه بر حسب سفر.
- Session auth + CSRF، ثبت مصرف واقعی با رضایت، حذف داده کاربران.
- گزارش و تأیید دستی موانع همراه تاریخچه تغییرات و جلوگیری از احیای موارد حذف‌شده.
- OpenTelemetry JSON logging, Loki, Tempo, Prometheus, Grafana و API راه دورِ محدود به مجوز.
- CI خودکار برای تست Python، تست PostGIS و migrations، ساخت Frontend، Compose config؛ انتشار Docker با workflow جداگانه.

## عملیات واقعی انجام‌نشده
- دانلود و Import واقعی PBF و داده موانع تهران روی سرور/DB عملیاتی.
- ساخت Graph OSRM و اجرای مسیر واقعی در سرور.
- استقرار HTTPS و راه‌اندازی زنده پایش، تست backup/restore و هشدار.
- اتصال داده ترافیک تهران و داده‌های DEM باکیفیت و آدرس‌یاب مستقل.
- تثبیت قابلیت تطبیق دقیق topology و جهت خیابان‌های هم‌نام/دوطرفه.
- آزمایش OBD واقعی با خودرو پراید، تحلیل آمار خطا و تأیید ضرایب قبل از انتشار علمی.
- benchmark بار، تست مرورگر end-to-end و ارزیابی امنیتی staging.

**کد قابل اجرا و CI سبز به معنای مصرف سوخت اندازه‌گیری‌شده یا استقرار آماده تولید نیست.**
